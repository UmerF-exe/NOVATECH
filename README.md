# NovaTech — Responsive Business Website

NovaTech is a fictional modern technology-business website created as a frontend development portfolio project.

## Technologies

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- Font Awesome
- Google Fonts
- Responsive Web Design

## Features

- Responsive navigation
- Hero section with image
- About section
- Services section
- Why Choose Us section
- Portfolio showcase
- Demo testimonials
- Contact form validation
- Responsive layouts for desktop, tablet and mobile
- Modern hover effects and UI transitions

## Important Note

NovaTech, its business information, portfolio projects, statistics, client names and testimonials are fictional/demo content created for portfolio demonstration. They should not be presented as real clients or real business results.

The contact form is a frontend demonstration and does not send emails until connected to a backend or form-processing service.
